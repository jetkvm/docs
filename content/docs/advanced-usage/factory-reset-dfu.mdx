DFU (Device Firmware Update) mode reinstalls JetKVM firmware over USB. Use it to recover a JetKVM with no microSD card slot.

If your device has a microSD card slot, follow the [microSD recovery](/docs/advanced-usage/factory-reset-microsd) guide instead.

> **Recovery erases your settings and stored data.** Back up anything you need before starting.

You need a computer, a **USB data cable**, and a thin pin. Connect JetKVM directly to the computer with the data cable.

## 1. Download the firmware

[Download the latest JetKVM recovery image](https://api.jetkvm.com/releases/system_recovery/latest?sku=jetkvm-v2) and save the `.img` file to your computer.

## 2. Enter DFU mode

1. Unplug the USB cable from JetKVM.
2. Locate the small hole on the right side of the device.
3. Insert a thin pin into the hole and gently press and hold the button inside.
4. While holding the button, reconnect JetKVM's USB cable to your computer.
5. Keep holding for three seconds, then release.

The recovery tool should detect a **MASKROM** device.

## 3. Flash the firmware

Choose your operating system: [Windows](#windows), [Linux](#linux), or [macOS](#macos).

### Windows

**Install the USB driver**

1. Download and extract [Driver Assistant v5.14](https://github.com/jetkvm/rv1106-system/releases/download/v0.2.5/DriverAssitant_v5.14.zip).
2. Open `DriverInstall.exe` and approve the administrator prompt.
3. Click **Install Driver** and wait for it to finish.

![Driver Assistant with the Install Driver button](/content/files/dfu-driver-assistant.png)

**Open RKDevTool**

1. Download [RKDevTool v3.37 (ZIP)](https://static.gl-inet.com/docs/kvm/tutorials/debrick_via_rkdriver/RKDevTool_Release_v3.37.zip).
2. Right-click the ZIP and choose **Extract All**. Open `RKDevTool.exe` from the extracted folder.
3. Select the **Upgrade Firmware** tab.

![RKDevTool v3.37 with the Upgrade Firmware tab selected and the Firmware and Upgrade buttons visible](/content/files/dfu-rkdevtool-upgrade.png)

**Flash the firmware**

1. Connect JetKVM in [DFU mode](#2-enter-dfu-mode). Check that the status says **Found One MASKROM Device**. If it says **No Devices Found**, see [Device not detected](#device-not-detected).
2. Click **Firmware** and select the downloaded `.img` file. Wait for it to load. **Chip Info** should show `RK1106`.

![RKDevTool with the JetKVM recovery image loaded in the Upgrade Firmware tab](/content/files/dfu-rkdevtool-firmware.png)

3. Click **Upgrade**.
4. Keep USB connected and the computer awake until the log says **Download Firmware Success**. JetKVM restarts automatically.

![RKDevTool showing Download Firmware Success after recovery](/content/files/dfu-rkdevtool-complete.png)

### Linux

1. Clone the [JetKVM system repository](https://github.com/jetkvm/rv1106-system) and enter the tool directory:

```sh
git clone https://github.com/jetkvm/rv1106-system.git
cd rv1106-system/tools/linux/Linux_Upgrade_Tool
```

2. Check that JetKVM is detected:

```sh
sudo ./upgrade_tool ld
```

3. Flash the image, replacing the path with your downloaded `.img` file:

```sh
sudo ./upgrade_tool uf "/path/to/your/firmware.img"
```

Wait for `Upgrade firmware ok.` before disconnecting USB.

### macOS

1. Download and extract [upgrade_tool v2.44 for macOS](https://github.com/jetkvm/rv1106-system/releases/download/v0.2.5/upgrade_tool_v2.44_for_mac.zip).
2. Open Terminal and change to the extracted folder containing `upgrade_tool`:

```sh
cd "/path/to/extracted/folder"
```

3. Check that JetKVM is detected:

```sh
sudo ./upgrade_tool ld
```

4. Flash the image, replacing the path with your downloaded `.img` file:

```sh
sudo ./upgrade_tool uf "/path/to/your/firmware.img"
```

Wait for `Upgrade firmware ok.` before disconnecting USB.

## Troubleshooting

### Device not detected

- Re-enter DFU mode, holding the button **before** connecting USB and for three seconds afterwards.
- Try another USB data cable or USB port. Avoid hubs and power-only cables.
- On Windows, reinstall the driver with Driver Assistant, reconnect JetKVM, and reopen RKDevTool.
- Disconnect any other Rockchip recovery devices.

### Windows blocks a download

Leave the file quarantined and keep Defender enabled. Use the Linux or macOS instructions instead.

### Flashing fails

If the image will not load, download it again from step 1 and select it under **Upgrade Firmware → Firmware**.

If flashing fails, save the error message, check the USB cable, and re-enter DFU mode before retrying.
